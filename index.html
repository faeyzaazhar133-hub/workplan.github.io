Install di iPhone / iPad

PT Pelican Mitra Sejati Workplan

1 Tekan tombol Share (Bagikan) di browser Safari.

2 Pilih menu 'Tambah ke Layar Utama' (Add to Home Screen).

3 Buka aplikasi workplan langsung dari ikon Home Screen HP Anda!

Cara Convert ke APK & Install di HP

Cara 1: Install Instan Tanpa File APK (Rekomendasi)

Aplikasi ini didukung oleh PWA (Progressive Web App). Anda bisa langsung memasangnya di Home Screen HP Android/iPhone tanpa perlu mendownload file APK terpisah.

Cara 2: Convert Menjadi File APK (Android)

Jika Anda membutuhkan file format .APK untuk dibagikan atau disimpan, Anda dapat menggunakan layanan converter gratis berikut:

WebIntoApp.com (Upload HTML to APK) PWABuilder.com (PWA to Android APK)

Langkah Install File APK di Android:

  1. Unduh file .apk dari converter di atas.
  2. Buka file .apk tersebut di aplikasi Manager File HP Android Anda.
  3. Jika muncul peringatan keamanan, izinkan "Install dari sumber tidak dikenal".
  4. Klik Install dan buka Workplan Pelican Mitra Sejati dari menu HP.
