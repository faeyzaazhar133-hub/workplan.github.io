Cara Tercepat (Install PWA Instan)

Aplikasi ini sudah mendukung PWA. Cukup tekan tombol "Install HP" di bagian atas header browser Google Chrome HP Anda untuk memasang langsung tanpa file APK.

Atau ubah file HTML ini menjadi file .APK gratis:

  1. Buka layanan converter web online seperti WebIntoApp.com atau PWABuilder.com.
  2. Upload berkas workplan.html ini atau masukkan URL web dashboard Anda.
  3. Klik "Generate APK" lalu download file .apk yang dihasilkan.
  4. Transfer file `.apk` ke smartphone Android dan pasang (install).
